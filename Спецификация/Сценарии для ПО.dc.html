Справочник пациентов и создание медкарты — сценарии прототипа

Как работает прототип «Справочник пациентов»: что видит пользователь, какие у него сценарии и что происходит в каждом состоянии.

1. Что решает раздел

  • Найти пациента сети клиник и посмотреть его данные и медкарты.
  • Создать нового пациента без дублей.
  • Создать пациенту медкарту в нужной организации.

Ключевой принцип: пациент создается один раз на всю сеть клиник, а медкарта — отдельно в каждой организации.

2. Роли

Переключаются в «Демо-настройках».

3. Экран «Справочник пациентов»

3.1 Фильтры (слева)

  • Город — обязательный. В списке только доступные пользователю города.
  • Организация — необязательная. Неактивна, пока не выбран город. Скрыта, если в городе одна клиника. Если не выбрана — в список попадают все доступные организации города. При смене города сбрасывается.
  • Сформировать — появляется, только когда фильтры изменены и список по ним еще не построен.
  • Сбросить фильтры — появляется, когда фильтры отличаются от исходных для роли.

В список попадают пациенты, у которых есть медкарта в выбранной области.

3.2 Шапка списка

  • Поиск по ФИО или телефону. Срабатывает от 3 букв ФИО или 4 цифр телефона, иначе под полем подсказка. Во время поиска — подпись «Ищем в текущем списке и в сети клиник…».
  • Добавить пациента — открывает создание пациента.
  • Пациенты (N) — без поиска число пациентов в списке, при поиске — число найденных в текущем списке.

Шапка видна, только когда выбран город.

3.3 Таблица

Колонки: ФИО, Дата рождения, Телефон, Медкарты. Сортировка по ФИО.

Колонка «Медкарты»:

  • выбрана организация — только номер карты;
  • выбран только город — номер и организация;
  • показывается максимум 2 карты, дальше ссылка «Еще N карт», она открывает правую панель.

Список подгружается порциями по 40 при прокрутке («Загружаем еще…»). При загрузке — скелетон.

3.4 Результаты поиска

  • Совпадения в текущем списке — в основной таблице.
  • Если в текущем списке пусто, но в сети найдены — строка «В текущем списке совпадений нет».
  • Блок «Найдены в сети клиник (N)» — пациенты без медкарты в выбранной области. До 20 записей, при большем числе — «Показаны первые 20 — уточните запрос». Медкарты указаны как «Город · Организация». В каждой строке кнопка «Создать медкарту»; неактивна с подсказкой, если у пациента уже есть карты во всех доступных организациях.

4. Правая панель пациента

Открывается кликом по строке (в списке, в блоке «Найдены в сети клиник», в списке похожих при создании). Закрывается крестиком, клавишей Esc или повторным кликом по той же строке. Клик по другому пациенту меняет данные в открытой панели. Выбранная строка подсвечивается.

Содержимое:

  • ФИО, дата рождения и возраст;
  • Контактные данные: телефон, email, адрес по прописке;
  • Общая информация: пол, гражданство, социальный статус, дата регистрации;
  • Документы: паспорт (серия, номер, дата выдачи, код подразделения, кем выдан), СНИЛС, полис ОМС;
  • Медицинские карты (N) — все карты в формате «Город · Организация» и номер. Если карт нет — «У пациента пока нет медкарт».

Пустые поля показываются прочерком.

Поведение зависит от места открытия:

  • Из справочника. Есть кнопка «Создать медкарту». Неактивна с подсказкой, если свободных организаций нет. Если у пациента нет медкарты в выбранной области — сверху желтый алерт «Нет медкарты в выбранной области».
  • Из формы создания. Внизу кнопка «Выбрать пациента», кнопки «Создать медкарту» нет.

5. Создание пациента

Открывается кнопкой «Добавить пациента». В шапке — хлебные крошки «Справочник пациентов / Создание пациента». Форма из двух шагов со степпером.

5.1 Шаг 1 — Основные данные

Поля: Фамилия*, Имя*, Отчество, Дата рождения*, Номер телефона, Email.

По кнопке «Продолжить» выполняется проверка на дубли по сети клиник:

Что совпалоЧто видит пользовательМожно продолжить?
НичегоСразу переход на шаг 2Да
ФИО + дата рождения, ФИО + телефон или только телефонЖелтый алерт «Найдены похожие пациенты» и списокДа, повторным нажатием «Продолжить»
ФИО + дата рождения + телефонКрасный алерт «Пациент уже есть в системе» и списокНет, «Продолжить» неактивна

Если после проверки изменить данные — алерт заменяется серой плашкой «Данные изменились. При нажатии «Продолжить» проверка выполнится заново».

Клик по шагу 2 в степпере работает так же, как «Продолжить».

5.2 Шаг 2 — Дополнительные данные

Сверху — сводка шага 1 (ФИО · дата рождения (возраст) · телефон) и ссылка «Изменить», она возвращает на шаг 1. Данные сохраняются.

Поля: Пол*, Гражданство, Социальный статус, Адрес по прописке, Паспорт (серия, номер, дата выдачи, код подразделения, кем выдан), СНИЛС, Полис ОМС.

Кнопка «Создать пациента» неактивна, пока не выбран пол. По нажатию — вторая проверка:

Что совпалоЧто видит пользовательМожно создать?
Паспорт, СНИЛС или полис ОМСКрасный алерт «Пациент уже есть в системе» и списокНет
ФИО + дата рождения или ФИО + телефон, при этом пол и документы не противоречатЖелтый алерт «Найдены похожие пациенты»Да, повторным нажатием «Создать пациента»
Только телефон или только дата рожденияНичегоДа

Пример: пациентка сменила фамилию. На шаге 1 совпадений нет, на шаге 2 совпал паспорт — создание блокируется.

«Назад» возвращает на шаг 1.

5.3 Карточка найденного пациента

ФИО · дата рождения · телефон, ниже «Совпадения: …» — какие поля совпали (ФИО, или отдельно фамилия / имя / отчество, дата рождения, телефон, паспорт, СНИЛС, полис ОМС).

  • Клик по карточке открывает правую панель.
  • «Выбрать пациента» — создание нового отменяется, открывается справочник с панелью выбранного пациента и сообщение «Открыт существующий пациент. Новый пациент не создан». У желтого алерта кнопка обычная, у красного — акцентная.

5.4 После создания

Открывается справочник с панелью нового пациента и модалка «Создать медкарту?»:

  • «Не сейчас» — сообщение «Пациент сохранен без медкарты»;
  • «Создать медкарту» — открывается модалка создания медкарты.

5.5 Выход из формы

«Отмена» на шаге 1 или клик по «Справочник пациентов» в крошках. Если что-то введено — модалка «Выйти без сохранения?» («Отменить» / «Выйти»).

5.6 Ошибка проверки

Если проверка не выполнилась — модалка «Не удалось проверить пациента» с кнопками «Отменить» и «Повторить».

5.7 Валидация

Ошибки обязательных полей шага 1 показываются при вводе или после нажатия «Продолжить», шага 2 — после нажатия «Создать пациента». При ошибках — сообщение «Проверьте заполнение полей»; если ошибка в полях шага 1, форма возвращается на шаг 1.

6. Создание медкарты

Модалка «Создание медкарты». Открывается из панели пациента, из блока «Найдены в сети клиник» или после создания пациента.

  • Строка «Пациент: ФИО».
  • Город* и Организация* подставляются из фильтров, если это возможно; если доступен один город или одна организация — подставляются автоматически.
  • В городе с одной клиникой поля «Организация» нет.
  • Организации, где у пациента уже есть карта, неактивны: «1905 года (медкарта № 580168)», подсказка «У пациента уже есть медкарта в этой организации».
  • Все организации города заняты — желтый алерт «У пациента уже есть медкарта в этом городе».
  • Все доступные организации заняты — желтый алерт «У пациента уже есть медкарты во всех доступных вам организациях».
  • «Создать медкарту» активна, когда выбраны город и свободная организация. Во время создания — спиннер.

Результат:

  • успех — сообщение «Медкарта № N создана · Организация», открыта панель пациента;
  • карту в той же организации уже создал другой сотрудник — модалка «Медкарта уже создана» с номером карты и кнопками «Создать в другой организации» (если есть свободные) и «Понятно».

7. Как пройти сценарии в прототипе

Кнопка «Демо-настройки» слева внизу:

  • Роль — переключение доступа.
  • Симуляция ошибок: ошибка загрузки списка, ошибка поиска, медкарту уже создал другой сотрудник.
  • Тестовые сценарии создания (на экране создания): Не найден, Один похожий, Несколько похожих, Полное совпадение, Совпали документы; флажок «Ошибка проверки в сети».
  • Для проверки медкарт введите в поиске «Тестов» — отчество подсказывает случай (1, 2, 3, 5, 8 карт, несколько городов, без карт).
